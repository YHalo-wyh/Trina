# 可独立验证的任务卡

本目录按用户行为切片，技术模块只用于定位实现。责任角色为仓库维护者、测试执行者和复核者，不填写未经确认的组员姓名。TASK-01 至 TASK-07 表示已有能力的复核归档；本次新增工作集中在 TASK-08。测试通过范围与剩余限制分别记录，不能仅以“已完成”覆盖所有风险。

## TASK-01 从任务输入到受控动作

**目标与关联。** 覆盖 REQ-01 至 REQ-04。操作者给定授权地址后，合法模型动作应进入注册工具；坏协议、未注册检查和坏参数应在相应关口停止，不能进入任意命令执行。

**输入、输出和资料。** 输入为规格第一节、`trina/cli.py`、`trina/brain/prompts.py`、`trina/policy.py` 与工具注册表。输出为协议、strict/guided 差别的准确说明，以及解析、目标和参数拒绝回归结果。资料按需读取相应模块，不向模型一次复制全部历史审计。

**允许范围与依赖。** 文档及测试执行可进行；本次不得修改 parser、控制器、ToolSpec 或授权配置。依赖 M0 基线确认，其他任务依赖本任务建立的工具和检查项概念。

**验证。** 执行 `python -m unittest discover -s tests -p test_brain.py`、`test_policy.py` 和 `test_registry.py` 对应命令。观察合法动作调用次数、预检模型零调用、strict 错配拒绝及参数错误。完整精确用例由追踪清单列出。

**DoR / DoD。** 注册目标和测试工具可用为 Ready；相关测试有真实结果、SC-P01/N01/A01/N02/N03 可追踪、strict 参数限制已说明为 Done。若需要重新解释裸主机继承或完整参数绑定，登记 OQ-02，不在此文档任务中扩大权限。

**责任、停止与回滚。** 测试执行者记录结果，维护者确认接口语义；发现默认模式或参数契约不符则停止该主张。恢复到原文档提交，不修改运行产物来匹配规格。

## TASK-02 动作风险与 HTTP 传输边界

**目标与关联。** 覆盖 REQ-05、REQ-06。工具风险随实际参数计算，HTTP 跳转不能把一次合法请求变成跨源或危险目的地访问。

**输入、输出和资料。** 输入为 `docs/GUARDRAILS.md`、`trina/scope.py`、`trina/tools/http.py`、外部工具包装器及动态等级测试。输出为动作分级和 303/307、重定向循环、POST 重试的行为契约及测试结果。

**范围与依赖。** 依赖 TASK-01。仅运行回环夹具和 mock 拒绝分支，不实际探测测试中的外部拒绝地址。本次不得增加 payload、第三方扫描器或绕过 HTTP 包装器的请求实现。

**验证。** 执行 `python -m unittest discover -s tests -p test_scope.py`、`test_http.py` 及 `test_eval_report_lab.py`。断言动态等级拒绝、跳转目的端零命中、303/307 方法语义、循环有界以及写请求不盲重试。

**DoR / DoD。** 回环监听和测试依赖正常为 Ready；SC-A02、SC-A03 和相关测试成立、文档没有把字符串规则写成完整语义沙箱为 Done。协议新增或编码变体未覆盖时记为限制。

**责任、停止与回滚。** 执行者保留传输失败及环境信息，维护者判断是否另开代码修复。出现未授权真实出网立即停止相关运行并保留轨迹。恢复测试环境，不放宽范围让用例通过。

## TASK-03 证据驱动发现与任务结论

**目标与关联。** 覆盖 REQ-07、REQ-08。同对象证据能够升级发现；不同对象、固定错误页、输入反射和模型伪造字段不能形成成功事实。

**输入、输出和资料。** 输入为 `trina/hypotheses.py`、`trina/brain/goal.py`、主控收尾、状态合并及阴性探针测试。输出为发现状态与运行 verdict 的明确区别、正反场景和证据对象匹配说明。

**范围与依赖。** 依赖 TASK-01，测试可与 TASK-02 独立运行。保留既有验证算法，不新增攻击路径，不修改模拟靶机来迎合测试。原始证据与派生的阴性夹具分别标识。

**验证。** 执行 `python -m unittest discover -s tests -p test_decision_evidence.py`、`test_probe_integrity.py`、`test_state.py`。同时检查主控完整回归中的无关 flag 捷径和 verdict 测试。

**DoR / DoD。** 验证对象的 URL、参数、漏洞类及证据已知为 Ready；SC-P02/A04/P03/N04 可定位，已验证事实不被超时抹去，误报边界如实说明为 Done。通用独立复现未实现，不能归入已完成内容。

**责任、停止与回滚。** 测试执行者提供原始输出，复核者判断证据是否足够。出现与阴性对照矛盾的已验证主张时停止推广结论，并保留最小复现输入。

## TASK-04 审计与分层可见性

**目标与关联。** 覆盖 REQ-09、REQ-15。执行记录可校验，列明的审计、报告和子角色快照位置隐藏虚构测试口令，同时准确标识原始状态的敏感性。

**输入、输出和资料。** 输入为 `trina/audit.py`、`Credential.to_dict`、报告生成和 `trina/tools/specialists.py`。输出为完整性试验、字段脱敏测试及 Raw/Derived/Masked 可见性表。

**范围与依赖。** 依赖 TASK-01，独立于其他产品验证切片。只使用虚构靶场凭据；篡改试验操作独立副本。本次不得修改历史审计，不能把原始 state 宣称为已全面脱敏。

**验证。** 执行 `python -m unittest discover -s tests -p test_audit.py` 及报告、咨询脱敏用例。校验正常追加、篡改/删除失败及快照口令缺失。检查精选 state 是否只含虚构数据，查看文件而非只信脱敏摘要。

**DoR / DoD。** 原始与派生文件明确、没有实际密钥输入为 Ready；SC-A05/P07 有实际输出，哈希链局限与 OQ-05 可见为 Done。若发现真实凭据，停止上传受影响产物并由维护者处理。

**责任、停止与回滚。** 证据整理者保留来源与摘要映射，维护者决定发布范围。回滚文档和提交清单，不删除原始事实以掩盖问题。

## TASK-05 人工介入、撤权与停止合同

**目标与关联。** 覆盖 REQ-10、REQ-11，并复核 REQ-03 撤权。操作者能够拒绝动作、输入提示和停止新调度，预算及无新增事实条件产生可解释的收尾。

**输入、输出和资料。** 输入为 `trina/session.py`、控制台、主控循环、Budget 和事实摘要。输出为审批等待、停止边界、多层预算及失败反馈的具体说明。

**范围与依赖。** 依赖 TASK-02 对等级及执行关口的确认。用可控测试等待和小测试预算验证，不改变仓库默认值，不将计费统计误称为金额限额。

**验证。** 执行 `python -m unittest discover -s tests -p test_interactive.py`、`test_policy.py`、`test_decision_evidence.py`。检查拒绝/超时零执行、hint 实际进入输入、停止后无新工具、撤权拒绝及重复事实触发停止。

**DoR / DoD。** 审批回调和事件夹具可用为 Ready；SC-N05/P04/A07/N06 成立、在途强取消限制注明为 Done。当前覆盖记账提前的问题不因这些用例通过而关闭。

**责任、停止与回滚。** 操作者决定批准与撤权，执行者记录真实结果。需要新增批准主体或恢复旧预算时停止并建立新契约；不在测试失败时把审批改为 off。

## TASK-06 状态快照、工作台与调度

**目标与关联。** 覆盖 REQ-12、REQ-13。工作台读取完整状态，保存失败不毁旧文件，连续调度依据当前控制器记录，明确检查 ID 错配不能算遵从。

**输入、输出和资料。** 输入为 `RunState`、`PentestAgent._save_state`、`trina/board.py`、调度器和 ADR-0018。输出为快照读写约束、状态模型及调度判据。

**范围与依赖。** 依赖 TASK-03 对事实的定义。使用临时目录和替换失败注入，不改真实历史状态；本次不实现新的 resume、共享数据库或黑板。

**验证。** 执行 `python -m unittest discover -s tests -p test_insight.py`、`test_collaboration.py`。检查状态 round-trip、替换失败保留旧文件、实时覆盖选择下一项、关闭调度不注入指令。

**DoR / DoD。** 临时文件系统支持替换为 Ready；SC-N07/P05 对应输出可查，`executed` 的实际语义写明为 Done。URL/参数细粒度匹配不足保持 OQ-04 开放。

**责任、停止与回滚。** 维护者确认字段和读者兼容性，执行者保留失败快照。发现状态 Schema 要改变时停止当前任务并先做迁移方案，不直接删除旧字段。

## TASK-07 专职建议到报告复核

**目标与关联。** 覆盖 REQ-14、REQ-16。子角色提供有界建议，执行权保留在主控和原执行链；报告与只读复核解释事实及缺口。

**输入、输出和资料。** 输入为角色定义、咨询工具、录制回放、报告和 review 模块。输出为角色白名单、咨询预算、主子响应顺序、报告阅读和人工签署边界说明。

**范围与依赖。** 依赖 TASK-04 的可见性约束和 TASK-03 的事实判据。固定后端测试咨询，不调用付费模型；不启用默认关闭的咨询配置，不引入自治多 Agent 执行。

**验证。** 执行 `python -m unittest discover -s tests -p test_collaboration.py`、`test_eval_report_lab.py`。断言咨询阶段无事实和工具执行、非法建议被拒、预算有界、录制回放对齐、空报告可渲染及缺证据 review 告警。

**DoR / DoD。** 模拟响应和注册工具可用为 Ready；SC-P06/A06/P08 有实际验证，未宣称咨询收益和人工批准为 Done。真实模型收益试验另列 OQ-06。

**责任、停止与回滚。** 维护者确认建议协议，复核者核对报告来源。子响应出现执行能力或未审计事实写入时停止该功能主张；保持开关关闭作为已有隔离方式。

## TASK-08 课程契约、综合验证与仓库交付

**目标与关联。** 覆盖 REQ-17 至 REQ-20，汇总所有前置切片。教师从 README 能找到完整文档，沿任一 REQ 找到场景、任务、测试和证据，当前执行结果与历史结果分开。

**输入、输出和资料。** 输入为原课件页码、当前代码、上述任务记录和公开测试。输出为课程文档、JSON 追踪清单、检查脚本、原始测试日志、两轮新靶机精选样本、审查记录及 Gitee 提交。课件全文和无关临时文件不入库。

**范围与依赖。** 依赖 TASK-05、06、07 的契约与结果。允许文档、验证脚本和精选 evidence；不改变目标权限、不新增依赖、不编造同行签署。课程书写按项目事实展开，不复刻论文平台功能。

**验证。** 执行 `python -m scripts.verify_course_pack`、`python -m unittest discover -s tests`、`python -m scripts.verify_decision_evidence --output <新目录>` 和 `git diff --check`。隔离副本中破坏引用检验文档检查能失败。推送后读取远端 main SHA，与本地 HEAD 比较。

**DoR / DoD。** 课件要求与产品边界清楚、证据目录唯一为 Ready；追踪和链接通过、真实输出已归档、问题和 AI 使用披露完整、远端一致为本次提交 Done。独立环境复现和教师签署维持待评审状态。

**责任、停止与回滚。** 仓库维护者接受提交，教师决定最终验收。关键测试失败时保留日志并解释，不隐去失败。远端冲突采用正常合并或新提交，禁止为了交付强推覆盖他人工作；回滚采用本次变更的反向提交。
