# AI 使用披露与人机责任

## 参与范围

本项目代码与文档存在 AI 辅助开发。对当前课程提交，AI 辅助读取课件结构、探索代码和测试、起草规格与场景、整理任务和双层 Harness、编写本地追踪检查，以及执行经维护者授权的回归、证据整理和 Git 提交。课件用于提取提交结构，产品行为依据源码及实际运行核对。

AI 生成的说明只是候选工程工件。路径有效性、测试名称和运行输出由机械检查核实，需求充分性、范围接受、实验推广和课程评价仍由人负责。本披露没有将未发生的人工审查写成已完成，也不编造其他组员的贡献。

## 权责

| 活动 | 人的责任 | AI 可承担的辅助工作与验证方式 |
|---|---|---|
| 问题与范围 | 维护者提出要提交的仓库、文档深度和目标；教师说明课程评价 | 整理 Intent、对照课件清单，保留来源及未决问题 |
| 产品安全与权限 | 维护者确认授权配置和高风险变更 | 阅读代码并起草规格，不能自行扩展白名单或降低拒绝断言 |
| 实现与任务 | 维护者接受设计及修改范围 | 按契约起草文档、脚本和任务卡，差异可审查，已有代码不冒充本次新工作 |
| 验证事实 | 执行者记录环境和原始结果，复核者判断证据适用范围 | 运行命令、保存输出及文件哈希，不生成虚假通过或隐藏失败 |
| 同行和教师审查 | 真实审查者抽查、复现、分级并签署 | 提供可定位的材料和自查，不能代签或给自己课程分数 |
| 仓库发布 | 维护者本次明确要求上传 Gitee | 正常提交推送并核对远端，不代为部署产品服务 |

## 未采纳的主张与原因

以下是文档准备过程中被事实约束排除的候选表述，不伪装成某位同学或教师的历史否决记录。

“267 项测试通过，所以所有注册检查已成功完成”未采纳。测试覆盖有限，且当前控制器在 policy allow 阶段就更新 executed。采用的表述为：公开测试验证其覆盖行为，实际覆盖统计另有生命周期限制。

“state.json 可以恢复任意中断任务”未采纳。现有 `from_dict` 支持状态重建与视图读取，控制器预算、撤权、模型上下文和在途操作没有完整恢复协议。采用的表述为：工程交接支持人工恢复上下文，产品自动续跑待实现。

“开启专职 Agent 后成功率更高”未采纳。当前只有角色边界、预算和回放的确定性测试，没有同模型同预算的真实任务对照。默认保留关闭，并把效果试验列入 OQ-06。

“审计哈希链证明所有记录绝对不可伪造”未采纳。链可以检测现有样本的修改和缺失，但没有独立签名及外部锚点。采用的表述为内部一致性与篡改检测，原始响应真实性需另外复核。
