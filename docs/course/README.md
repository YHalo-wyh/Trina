**教师检查请先阅读根目录的[《开题报告与第一次汇报》](../../开题报告与第一次汇报.md)。** 本目录提供该报告的具体规格、计划、任务卡及工程附件。

2026-10-26 技术补充：[决策层设计说明](../DECISION_LAYER.md)逐步解释行为及设计依据，配合修订后的架构和 ADR-0001 阅读。本补充不修改产品逻辑；[本轮核对结果](../../evidence/20261026-decision-docs/README.md)单独归档，2026-10-21 的测试与证据继续保留原版本。

文档基线：2026-10-21，规格版本 `1.0`，产品代码基线 `24fb6371a18ed59c905de25bbf0ac69ba69ec256`。本目录面向《AI 原生工程实践》章节 02 的仓库检查。项目对象是已有的 Trina 安全测试 Agent，课件中的论文评审平台用于讲解方法，其角色和业务接口不属于 Trina 的交付范围。

Trina 接收授权靶场地址和测试目标，通过模型提出动作，由确定性控制器、工具注册表和范围护栏逐步裁决，最后保存状态、审计和报告。教师可以沿下表检查“为什么做、必须做到什么、怎样实现、怎样证明”。本文档包描述已有实现并补齐工程契约，未重新实现扫描器或改变授权配置。

## 三条检查命令

在仓库根目录执行，`python` 指向安装了项目依赖的 Python 3.10 及以上环境。Windows 现有虚拟环境对应 `.venv\Scripts\python.exe`，Linux/WSL 对应 `.venv/bin/python`。

```bash
python -m scripts.verify_course_pack
python -m unittest discover -s tests
python -m scripts.verify_decision_evidence --output artifacts/course-pack-demo
```

第一条检查文档、追踪关系、代码位置和实际测试名称，不执行模型或目标请求。第二条运行自动化回归，其中部分用例会创建回环服务和执行本地扫描。第三条使用固定模型决策及两套全新回环靶机验证真实请求、漏洞证据、假设状态、审计和报告，输出目录必须尚不存在。第三条不需要 API Key，也不测量真实大模型的规划水平。
