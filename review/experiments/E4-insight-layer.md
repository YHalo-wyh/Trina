# 实验卡 E4 · 洞察层（假设台账 + 失败分类/循环守卫 + 证据图）是否真的可解释、能换路？

- **Claim**：给 Agent 加"假设台账 + 失败分类 + 循环守卫 + 证据关系图"之后，
  (a) 每步动作能追到它要验证的假设；(b) 同一动作无新信息重复时系统会改变策略（换参数→换工具→请人介入）；
  (c) 结论能反向追溯到证据；三者都不引入额外越界或误确认。
- **状态**：**部分完成**——机制与可追溯性已验证（单次运行 + 故障注入）；
  "是否提升任务通过率/成本效率"**没有 A/B 对照**，本卡不作该结论。
- **固定条件**：靶机 = 内置模拟器（lab，HTTP 9099，仅回环）；模型 = `deepseek/deepseek-v4-flash`；
  动作上限 `verify`；注册检查项 = `configs/ranges/lab.yaml` 的 11 项；`run.hypothesis_risk_aversion = 1.0`
- **唯一主要自变量**：是否启用洞察层（现状 = 启用；对照臂 = 仅当步 `thought`，未执行）
- **无法控制的变量**：模型采样（同一提示词路径不同）→ 单次运行只能验证机制，不足以比较效果

## 结论边界（能说什么 / 不能说什么）
- ✅ 可以说：假设状态由**工具结果**确定性推进（不采信模型自我宣告）——本轮 2 条 confirmed 都伴随新发现，
  2 条无确凿证据的假设被显式标为"未解决"，**没有**被伪装成已确认。
- ✅ 可以说：环境类失败被单独归因（`fail_environment_error`），并能触发"换参数/换工具/人工"的递进建议；
  无新信息重复有了可读刻度（`redundant_action_rate`）。
- ✅ 可以说：结论→证据→检查项/假设的关系可离线绘出（mermaid / 节点表），复核不必逐行读日志。
- ❌ 不能说：洞察层**提升**了通过率或降低了成本——对照臂（不用台账/守卫）未跑，样本量 1。
- ❌ 不能说：模型一定愿意提假设——轮次 2 中模型就没有提，台账为空；本轮**未**采用"强制字段"的做法。

## 下一步（把实验做完整）
1. 加一个开关（`run.hypothesis_ledger: off`）跑对照臂，同任务重复 ≥3 次，比较：覆盖项数、耗时/步数、token 成本、`redundant_action_rate`；
2. 把"未解决假设"接进下一轮的起点（跨轮接力），验证"跨轮不重复劳动"；
3. 若对照臂在相同预算下覆盖与检出不降，则把洞察层视作纯收益；若成本明显上升，则在 ADR-0015 里补"预算阈值下关闭"的开关口径。
