# 实验卡 E5 · 决策与证据判定一致性

日期：2026-10-16。

## 验证问题

新增疑似发现能否误确认假设？既有发现升级是否能被识别？重复事实能否绕过无进展停止条件？模型能否通过结束声明伪造成功或 flag？

## 固定条件

- 决策输入：固定 ReplayBackend 脚本，不调用在线模型。
- 单元回归：真实注册表、控制器与状态合并，工具输出由测试夹具提供。
- 集成回归：两轮新建内置 HTTP lab，端口由系统分配；真实 `sqli_test` 请求经现有 HTTP 护栏执行。
- 集成授权：内存注册目标及 `sqli_recheck` 检查项，strict 模式；不修改持久化授权配置。
- 样本：内置模拟 SQL 注入接口；不代表真实数据库或公开基准题目。

## 结果

完整测试 **210/210 通过**，新增证据决策测试 **13/13 通过**。两轮集成运行均得到：

- 1 条带 HTTP 证据的 SQL 注入发现。
- 结构化验证对象匹配的假设进入 `confirmed`。
- 运行状态 `success`，结论 `CONFIRMED`。
- 审计链完整，各 17 条记录；复核没有缺证据声明和结论冲突。
- Markdown/HTML 报告、运行状态、审计和复核记录均已保存。

新增测试确认：`detected`、无证据验证状态、其他位置或其他漏洞类的发现均不能确认当前假设；同 ID 发现升级可以确认；重复事实触发停止合同；`final` 中的成功和 flag 声明不能改写事实。

## 结论边界

该实验验证执行机制和判定规则，未测量自主规划成功率、模型费用改善、失败恢复率或 TSecBench 成绩。完整工具验证器仍属于可信计算部分，独立 PoC 重放与修复复测尚未实现。

E4 中“新发现即可确认假设”的旧规则已被更严格的验证对象匹配规则替代。历史工件保留原样，其单次结果不能充当新规则的验收依据。
