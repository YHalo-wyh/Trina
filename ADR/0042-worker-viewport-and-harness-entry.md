# ADR-0042 Worker 四格视口与项目级 Harness 入口

状态：已实施 · 2026-11-22

## 背景

多任务并发时，较多卡片会压缩单个对话的可读空间。项目级 Harness 也需要从仓库首页直接进入，方便找到验证和恢复流程。

## 决定

- Worker 面板每屏最多显示两行两列，窄屏或放大时显示单卡。滚轮按行移动视口，右侧滚动条支持拖动到当前批次末尾。
- 视口按任务总数计算滚动范围，只对可见对话排版。翻页键用于浏览选中卡片的对话历史。
- 根目录 `harness/` 保存项目级 Harness 入口和清单。课程文档的旧路径保留跳转，规约和校验脚本引用根目录的清单。

## 验证

Worker 测试覆盖单屏四格、窄屏回退、历史缓存以及滚动访问第 137 个任务。项目级入口由机器规约与课程链接检查验证。[Worker 测试](../tests/test_worker_dashboard.py) · [Harness](../harness/README.md)
