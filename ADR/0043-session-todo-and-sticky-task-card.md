# ADR-0043 会话任务清单与固定任务卡

状态：已实施 · 2026-11-24

## 背景

Swarm 已有调度器内部 Todo，但普通 ChatAgent 的多步任务只能从对话和工具日志推断进度。一次性计划不能表达步骤已开始、完成、阻塞或取消，也不能随 `/resume` 恢复。把清单仅画在界面里又会形成第二份状态源。

## 决定

- 新增会话级 `TodoList`，状态为 `pending / in_progress / completed / blocked / abandoned`，每项使用稳定 ID，可选阶段和说明。
- 注册 `todo` 工具。复杂且有三个以上可验证步骤时，Agent 建立清单，并在步骤状态变化时更新；普通问答不创建清单。工具仍经 `ToolRegistry`，更新发布 `todo.updated` 事件。
- `ChatAgent` 快照保存完整清单，`/resume` 只恢复状态，不发模型请求或重放动作。
- 主终端固定显示有界任务卡，优先展示进行中、阻塞和待处理项；卡片不建立独立滚动区。`/tasks` 显示完整清单，避免争用主 transcript 的滚轮事件。
- UI、模型工具和持久化读取同一个 `TodoList`。Swarm 的调度 Todo 保持独立，因为它表示跨 Worker 的任务图，而会话清单表示当前 Agent 的交付步骤。

## 取舍

固定卡片最多投影少量开放任务，防止短终端失去主要输出空间；完整内容由 `/tasks` 查看。清单用于可见进度和恢复，不代替工具执行、测试或结论证据。

## 验证

`tests/test_todo.py` 覆盖状态变更、重复项、工具事件、跨会话恢复和固定卡片折叠；`tests/test_tool_profile.py` 验证任务清单工具在通用与文件任务路由中可见。
