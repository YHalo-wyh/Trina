# ADR-0041 执行前澄清与并行任务观察

状态：已实施 · 2026-11-21。网格布局更新见 [ADR-0042](0042-worker-viewport-and-harness-entry.md)。

## 背景

任务说明可能遗漏交付格式、工作范围或验收条件。并发运行时，操作者还需要区分可立刻交给 Agent 的补充和暂存草稿，并观察各 Worker 的对话和终态。

## 决定

- `/plan` 使用独立的无工具文本对话，返回一个待选问题或一组验收标准。用户可选择编号或填写自定义答案，由 `/plan queue` 收下最终草稿，再显式发送。
- 运行中普通输入保留在草稿队列。立即发送仍通过现有 `/hint` 和决定点介入边界。Worker 草稿保留批次和任务身份，避免误投同名任务。
- 后台作业和 Worker 终态通过主会话通知。界面订阅既有事件及已经提交的状态，终态提示仅供操作者查看。
- 网格宽屏显示九格，中屏显示四格，窄屏显示单格。分页、放大和历史浏览沿用 Worker 对话的有界缓存。

## 验证

澄清流程、显式发送和终态提醒由控制台测试覆盖。网格回归验证九窗格同时出现、跨页、尺寸约束和对话缓存复用。[控制台测试](../tests/test_interactive.py) · [Worker 视图测试](../tests/test_worker_dashboard.py)
