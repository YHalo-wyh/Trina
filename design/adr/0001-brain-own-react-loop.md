# ADR-0001：决策大脑自研 ReAct 循环，omp 只做模型接入

- 状态：已采纳（M1）
- 相关：ADR-0002、ADR-0004

## 背景
项目使用自研 Python ReAct 决策循环，并通过可替换后端接入模型。omp 后端提供模型与鉴权接入；其自带 agent loop（工具调用、上下文管理、压缩），
看似可以直接复用；但本项目的评分点是**受控、可审计、可复现**：每一次动作都要过护栏、写审计、计入指标，
并且要在评测中给出确定性结论。

## 决定
决策大脑（观察 → 思考 → 动作 → 观察）自研，放在 `trina/brain/`；
omp 只承担它最强、最难自建的部分：**模型接入与鉴权**（`omp -p --mode=json`，返回文本 + usage/cost）。

## 后果
- 正面：护栏/审计/超时/停滞检测/预算全部在自家循环里，行为确定；评测指标可归因到具体步；离线回放可行。
- 负面：需要自己写提示词工程与解析容错（用多级回退解析与录制/回放缓解）。
- 风险控制：omp 侧用 `--no-tools`，避免它绕过护栏自己执行工具。

## 被否决的方案
用 omp 的内建 loop 直接跑（工具注册成 omp 工具）：省事，但护栏与审计会被"框架内部行为"稀释，
且无法对每步做超时/预算/停滞控制，评测结论不可复现。
