## 回归中的问题记录

最初完整回归暴露委派工具误归到“只读协作查询”分类，触发既有目标参数契约。已将其改为 delegation 分类，保留原测试断言；普通 Worker 的核心协作工具不再自动添加委派 schema。委派执行仍由原有护栏和审计链控制。

首次独立快照完整检查还发现：无委派宿主的 CTFY 加载新工具后，小窗口在发送前耗尽预算。已修复为按宿主过滤合同和 schema，不扩大测试预算或删除断言。同轮软404 HTTP 检查出现 Windows `ConnectionAbortedError(10053)`，复现后发现 lab 未知 POST 路由未读请求体就关闭连接。已补充读取请求体，维持软404响应与原断言；真实失败保留于首轮记录，后续回归结果单独记录。

## 结论边界

本轮支持控制台聊天及控制台 `/run`、`/play` 的 Commander 委派；无宿主入口明确不可用，不递归扩大 Worker。支持有界结果查询、定向补充和取消、四格实时观察；这不等于接管完整 Worker 聊天。已有会话保留旧 system，更新提示词需 `/new`。
