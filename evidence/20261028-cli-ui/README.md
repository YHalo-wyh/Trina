## 验证对象

- 新增 `trina/terminal.py` 的首页、卡片、步骤、审批和文本降级渲染。

- `cli.py` 的一次性 run/play 展示、颜色开关转发和重定向 watch 行为。

验证证明的是相应交互分支、文本边界和既有回归行为；没有据此宣称安全测试成功率提高、模型注意力提升或多 Agent 收益已被证明。覆盖底层生命周期、在途取消及全流程敏感内容治理仍保留原未决问题。
